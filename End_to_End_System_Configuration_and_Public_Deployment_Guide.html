3. Best System Requirements

Item Best recommendation Why this is the best fit
Application OS Windows Server 2025 with Desktop Experience Best fit for Python runtime, IIS hosting, Office automation, SAP GUI, and document-processing tasks.
Application CPU 12 to 16 vCPU Supports web traffic, OCR, file uploads, PDF generation, Excel refresh, and SAP automation.
Application RAM 32 to 48 GB Needed for OCR, Torch/EasyOCR libraries, Office processes, browser rendering, and large uploaded files.
Application storage 500 GB to 1 TB NVMe Supports uploaded documents, generated PDFs, temporary OCR files, workbooks, and logs.
Database OS Windows Server 2025 or 2022 Good fit for SQL Server and a separate private data tier.
Database engine SQL Server 2022 or later supported release Matches the repository's SQL Server and ODBC-based design.
Database sizing 8 vCPU, 32 GB RAM, 1 TB SSD/NVMe Practical baseline because records and some document binaries are stored in SQL Server.

4. Software You Must Install

Software Required Notes
Python 3.10 x64 Yes Safest choice for this repository because the current environment and dependencies align to Python 3.10.
ODBC Driver 18 for SQL Server Yes Required for SQL Server connectivity. Driver 17 also works with the current code.
Google Chrome or Microsoft Edge Yes Needed for browser-based PDF rendering and related browser-driven operations.
IIS + URL Rewrite + ARR Yes for public hosting Used to publish the portal securely over HTTPS as a reverse proxy.
Microsoft Excel desktop Yes for full flow Needed for the vendor upload workbook and Excel refresh pipeline.
Microsoft Word desktop Recommended for full flow Used in DOCX preview and PDF conversion paths.
SAP GUI for Windows with scripting installed Yes for SAP flow Required when the process must create vendor codes through SAP GUI scripting.
Tesseract OCR Conditional Needed when the OCR path depends on local Tesseract.
